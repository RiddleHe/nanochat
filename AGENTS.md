# Agent workflow

For sustained research, experiment design, result interpretation, or requested
workflow setup, use `.agents/skills/research-workflow/SKILL.md`. Simple questions
and edits do not need the full workflow.

Reuse established project memory. If `.research/` exists, read STATE.md and
CURRENT_TASK.md at task start or recovery, then use INDEX.md for targeted retrieval.
Reconcile old records with the latest user request; do not preload whole histories.
Keep private state and credentials out of commits. Creating a plan does not
authorize experiments, external messages, or publication beyond the user's request.
