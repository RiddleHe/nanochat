# Project runbook

## Recovery

Read STATE.md and CURRENT_TASK.md, reconcile with the latest user instruction, then
use INDEX.md to retrieve only relevant task records and evidence. Recheck live jobs
before reporting status or resuming work. No automatic compaction hook is installed.

## Task setup

Preserve the user's intent. Record goal, deliverable, evidence, constraints,
authorization, unknowns, and success checks. Simple requests need no formal card.

## Validation

Record actual baseline/reference checks and experiment invariants here when known.
Separate software correctness from evidence for a scientific claim. Do not treat
missing validation as passed.

## Memory updates

At meaningful decisions, launch, result/failure, and handoff, update the task record
and short current state. Preserve failed attempts and qualifiers. Link large logs
and exact result files instead of pasting them into startup memory.

## Project-specific execution

No compute service, account, budget, or launch command is configured. Add verified
non-secret operational details only when required and authorized for this project.
